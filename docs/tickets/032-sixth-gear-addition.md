# チケット 32: ギア6（6速）の追加とトランスミッション整合

## 目標

ニュートラル（gear 0）の導入により前進ギアが1〜5速（ギア5）までとなっていた既定のトランスミッション設定を見直し、ギア5の上としてギア6（6速）を追加する。変速比、UI操作・表示、キーボード変速、物理計算、およびテストを6速仕様へ整合させる。

## 調査根拠

`src/engine/drivetrain.ts` の `DEFAULT_DRIVETRAIN_CONFIG.gearRatios` は `[0, 11.5, 7.5, 5.4, 4.2, 3.4]` と定義されている。インデックス0がニュートラル（比率0）として導入された際、配列長6の末尾がギア5（3.4）となり、本来意図されていた6速マニュアル構成の前進6速目が欠落している。
これに伴い、`src/app/App.tsx` のギア選択ドロップダウン（`drivetrain-gear`）および前進ギア比編集欄（`Forward gear ratios`）で5速までしか選択・編集できず、キーボード変速（↑/↓）も最大ギア判定（`lastGear = drivetrainConfig.gearRatios.length - 1`）により5速で頭打ちになっている。

## 範囲 / 非対象

- 範囲: `DEFAULT_DRIVETRAIN_CONFIG` へのギア6比率の追加、UI（ギア選択・ギア比編集・キーボード操作・ラベル表示）の整合、多言語辞書（チケット28導入時）の対応、物理モデル・Worklet・Controller・E2Eテストの更新。
- 非対象: リバースギア（R）の追加、多段オートマチック等の動的自動変速物理、クラッチ滑り熱物理、特定実車の変速比の完全再現。

## 実装契約と想定ファイル

- `src/engine/drivetrain.ts`:
  - `DEFAULT_DRIVETRAIN_CONFIG.gearRatios` を `[0, 11.5, 7.5, 5.4, 4.2, 3.4, 2.8]` （または合意された巡航用変速比）へ更新する。
  - `validateDrivetrainConfig` の現行上限（ニュートラル + 最大15前進段、比率 0.1〜20）との整合性を維持する。
- `src/app/App.tsx`:
  - ギア選択セレクトボックスの並び順（`1 → N → 2 → 3 → 4 → 5 → 6`）が正しく描画され、ギア6が選択可能であること。
  - `gearOrdinal(6)` により `"6th gear"` と表示されること。
  - 前進ギア比編集欄（`Forward gear ratios`）に `Gear 6 ratio` 入力欄が表示され、変更・適用できること。
  - キーボード変速（↑/↓）で 5速から6速へシフトアップでき、6速で正しく最大段数に制限されること。
- `src/locales/` (チケット28導入時):
  - 日本語・英語のギア段数表示で6速の訳語（例: 「6速」 / 「6th gear」）を整合させる。
- テストファイル（`tests/engine/drivetrain.test.ts`, `tests/audio/controller.test.ts`, `tests/audio/engine-audio-processor.test.ts`, `tests/e2e/worklet.spec.ts`）:
  - 既定値でギア6が利用可能であることの単体テストを追加。
  - ギア6選択時、同RPMでギア5より車速が高く、負荷トルクが有限値として伝達されることの検証。
  - 上限外（ギア7以上、負値）の拒否テスト。
  - E2Eでのギア6選択・キーボード変速・車速増加の検証。

## 受け入れ基準

- 既定の Drivetrain 設定でニュートラル（gear 0）および前進6段（gear 1〜6）が設定されている。
- ギア6選択時に、同回転数においてギア5よりも高い車速が得られ、適切な負荷トルクが伝達され、有限な物理値（RPM、車速、負荷トルク）が維持される。
- UIのギアセレクトボックスに「6th gear」（日本語時は「6速」）が表示され、選択できる。
- キーボード操作で 5th gear から ↑ キーで 6th gear へ変速でき、それ以上のシフトアップは 6th gear を維持する。
- ギア比設定欄に Gear 6 ratio が表示され、0.1〜20 の範囲で設定変更・適用できる。
- 範囲外のギア番号（7以上、負値）の指定が弾かれる。
- 既存のテストおよび Docker による CI（`make test`, `make e2e`, `make check`, `make ci`）がすべて成功する。
