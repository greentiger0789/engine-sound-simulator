## Acceptance evidence

- `tests/audio/m3-offline-regression.test.ts`, `renders every M3 preset at idle,
mid, and full throttle across fresh and restarted offline lifecycles`, runs the
  real `EngineAudioProcessor` for the single-cylinder and all five
  multi-cylinder presets. Every matrix cell renders 0.256 seconds through a
  fresh and recreated processor, requires the native configuration/ready
  messages and no fatal processor message. Both 96 normal 128-frame quanta and
  an uneven `127/257/4096/4096/3712` partition cover the same 0.256-second
  duration, requiring deterministic reset-equivalent PCM, nonzero output,
  finite samples, and an absolute peak no greater than 1. Contiguous PCM must
  also match exactly between the normal and uneven partitions.
- The same file's three parameterized fixed-6000 RPM cases derive circular
  firing positions from the production `FiringEventGenerator.advanceRealtime`
  caller-owned sample-index/offset buffers rather than rereading preset angles.
  They require the 180-degree twin to emit `180°/540°`, the 270-degree twin
  `270°/450°`, and the 360-degree twin `360°/360°` intervals.
- `tests/e2e/worklet.spec.ts`, `covers the product start, stop, rejected reapply,
and successful retry flow`, reaches `running` only after the initial native
  Worklet handshake, stops to `idle`, stages a twin while stopped, observes a
  visible typed `config-rejected` error on the second Worklet construction,
  corrects and restages the stopped configuration, then observes successful
  promotion on the next native-ready start. The suite executes this product
  flow against both Vite development and Nginx production images.
- Existing product E2E cases continue to cover normal stopped four-cylinder
  promotion, all three active twin firing strips, controller restart, typed
  module-load and processor errors, analyser recreation, and throttle/load
  controls. The full unit/offline suite retains the existing single-cylinder,
  dynamics, event, DSP protection, controller, and visualization regressions.
- [README](../../../README.md) documents `make dev`, the localhost URL,
  start/stop and stopped-only configuration workflow, the 1–4-cylinder 720°
  scope, twin interval models, synthetic rather than measured values, and
  features deferred beyond M3.

## Review

- Self-review covered the complete `origin/main` working diff: matrix
  completeness, non-silent PCM evidence, finite/peak protection, deterministic
  Worklet recreation, fixed-RPM interval derivation, native E2E handshake and
  failure injection, README accuracy, and preservation of existing behavior.
- Two bounded Terra medium `ticket-worker` agents implemented non-overlapping
  offline/unit and E2E test paths. The orchestrator retained integration,
  documentation, reporting, numerical review, Git, and delivery ownership.
- Initial integration review found that one 4,096-frame matrix render could end
  before the first 720° event at 1,200 RPM, allowing silence to pass. The matrix
  was first expanded to three blocks and was later replaced by the final
  128-frame/uneven partition coverage described below. Both paths cover 0.256
  seconds, require nonzero output, and compare fresh/recreated PCM exactly. The
  orchestrator also removed a superseded E2E failure-option alias and corrected
  README wording so user volume is not described as a preset model value.
- A fresh Terra high `ticket-reviewer` found three test-evidence gaps: twin
  intervals used the checked allocation path instead of production realtime
  storage, a deterministic fatal fault after initial signal could pass the
  finite/peak matrix, and only maximum-size 4,096-frame blocks were exercised.
  Corrections use `advanceRealtime`, reject every `fatal-error`, and run both
  normal 128-frame quanta and an uneven partition for every matrix cell. The
  first recheck found that the partitions were independently safe but not
  compared; exact contiguous PCM equality across both partitions was added.
  Final independent correction recheck confirmed every finding resolved and
  reported no remaining actionable defect.
