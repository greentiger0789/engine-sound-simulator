## Scope

- Ticket: [aliasing 対策とバンク別経路の土台](../017-aliasing-and-bank-path-foundation.md)
- Reviewed implementation revision: pending before the implementation commit.
- Added a fixed-capacity bank signal router and per-bank combustion-pulse DSP
  state. Firing events carry their original cylinder index through chronological
  sorting, route by `bankId`, and merge into the existing single exhaust path.
- Added an allocation-free fixed-histogram block-budget meter to the production
  AudioWorklet path. The budget is derived from the actual frame count and
  sample rate.
- Measured the existing analytic `x² exp(-2x)` combustion source at every preset
  redline. Its source-side smooth pulse already meets the defined Nyquist guard,
  so oversampling/decimation was not added.
- Defined the real-time support envelope as at most 12,000 rpm and 800 aggregate
  firing events per second, rejecting unsupported snapshots before they replace
  a healthy Worklet runtime. Rotational integration also clamps each 1 kHz step
  to the configured redline so extreme finite torque/inertia cannot overshoot
  the validated envelope before the limiter reacts.

## Acceptance evidence

- `tests/audio/ticket17-aliasing.test.ts` renders every preset at its configured
  redline at 44.1 and 48 kHz after a one-second warm-up. A 32,768-frame Hann FFT
  requires the top 10% below Nyquist to remain at least 80 dB below total non-DC
  energy on the combustion source before exhaust resonance. This is the
  source-side decision gate against discontinuous excitation; it does not rely
  on a final low-pass filter.
- The observed source Nyquist-guard ratios (dB) were:

  | preset                     | 44.1 kHz |  48 kHz |
  | -------------------------- | -------: | ------: |
  | single-cylinder-model      |  -126.08 | -128.11 |
  | parallel-twin-360-model    |  -125.11 | -126.46 |
  | parallel-twin-180-model    |  -121.00 | -122.74 |
  | parallel-twin-270-model    |  -120.16 | -126.29 |
  | evenly-spaced-triple-model |  -124.46 | -114.06 |
  | evenly-spaced-four-model   |  -124.12 | -124.72 |

- The same test separately runs the actual Worklet final mix near each preset's
  limiter boundary, including exhaust, seeded intake, mechanical orders and
  final protection. It requires finite PCM, peak at or below 1, and a top-10%
  Nyquist guard of at most -45 dB. Observed final-product ratios (dB) were:

  | preset                     | 44.1 kHz | 48 kHz |
  | -------------------------- | -------: | -----: |
  | single-cylinder-model      |   -59.62 | -60.25 |
  | parallel-twin-360-model    |   -51.83 | -52.23 |
  | parallel-twin-180-model    |   -56.98 | -57.15 |
  | parallel-twin-270-model    |   -55.32 | -55.64 |
  | evenly-spaced-triple-model |   -50.50 | -50.97 |
  | evenly-spaced-four-model   |   -50.92 | -51.40 |

- `tests/engine/config.test.ts` verifies the 12,000-rpm ceiling and the exact
  800-event/s boundary. At the Worklet's 4,096-frame/44.1-kHz worst supported
  block, this is fewer than 75 events versus 512 slots. The maximum pulse tail
  permits at most 160 overlapping events versus 256 slots, and the maximum
  mechanical order is 6.4 kHz at 12,000 rpm, below 44.1-kHz Nyquist.
  `tests/audio/engine-audio-processor.test.ts` verifies an unsupported
  replacement is rejected without replacing or faulting the healthy runtime.
  A hostile-but-valid `1e100`-Nm / `1e-100`-kg·m² product case reaches but never
  exceeds 12,000 rpm, remains finite/protected, and emits no fatal error;
  `tests/engine/dynamics.test.ts` directly verifies the same redline clamp.

- `tests/audio/bank-signal-router.test.ts` verifies first-seen bank ordering,
  coincident two-bank routing, exact single-bank summing, variable block reset,
  bounds, and atomic rejection. `tests/audio/engine-audio-processor.test.ts`
  verifies the production Worklet routes sorted events to their original banks,
  produces finite protected output, and records actual block budgets.
- `tests/engine/phase-events.test.ts` verifies realtime events preserve the
  original cylinder index even when firing-angle sorting changes event order.
  The Worklet integration test uses a reversed 360-degree twin and observes only
  the early event's specific bank before the late bank fires, so an index swap
  cannot satisfy the assertion.
- The 48 kHz / 128-frame production processor harness in
  `tests/audio/ticket17-aliasing.test.ts` warms 250 blocks and measures 2,000
  blocks using four cylinders split across two bank routes at 98% of the
  configured redline. The observed p99 was 0.121 ms, below the half-block target
  of 1.333 ms (full block: 2.667 ms). This Docker/Node harness is not a physical
  browser profiler result.
- Existing single-bank presets remain on one route and the full product
  regression continues to verify deterministic finite output at 44.1/48 kHz.

## Review

- Self-review covered bank/cylinder identity across event sorting, bounded
  storage and atomic failures, single-bank mixing, configuration replacement,
  finite output, spectrum methodology, and production-path allocation/logging.
- Self-review found that returning the generator's sorted-array position would
  misroute configurations whose source cylinder order differs from firing order.
  The generator now retains and emits the original index, with focused engine
  and product Worklet regressions.
- A bounded Terra medium ticket worker implemented the independent bank-router
  module and focused tests. The orchestrator owns event contracts, Worklet
  integration, spectrum/performance evidence, documentation, Git, and delivery.
- Independent Terra high review found three acceptance-evidence gaps: no finite
  RPM/event-density support envelope, a post-resonator spectrum being used to
  justify source bandwidth, and a bank integration assertion that could not
  distinguish swapped identities. The corrections add configuration ceilings
  with safe-replacement coverage, separate pre-resonator and final-product
  spectrum matrices, and a discriminating early/late bank assertion. Reviewer
  recheck then found that extreme finite torque and inertia could overshoot the
  configured bound within one dynamics step. The final correction clamps the
  rotational state at redline and adds core/product hostile-input regressions;
  the reviewer confirmed the correction resolves the remaining finding and
  reported no actionable findings in the current diff.
