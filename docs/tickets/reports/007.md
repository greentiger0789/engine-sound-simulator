## Acceptance evidence

- `tests/engine/phase-events.test.ts` verifies exactly 50 angle-zero events in
  one second at 6000 rpm for both 44.1 and 48 kHz, with expected absolute frame
  positions.
- The same test compares a one-second render with uneven `1, 127, 13, 256, 37`
  frame partitions at both sample rates. A separate a-rate sequence changes
  angular velocity at fixed sample positions and produces the same cycle,
  sub-sample offset, and absolute-frame event sequence under those partitions.
- Explicit half-open boundary cases assign a crossing at one sample's end to
  the next sample, including the 720-to-0-degree cycle boundary. Zero angular
  velocity produces no events, and coincident cylinders are sorted by ID.
- Boundary cases reject non-finite or negative velocity, invalid sample rates,
  discontinuous frames, unsafe absolute phase, and excessive per-sample event
  density. A late numerical failure test confirms that phase and frame state
  remain unchanged for the entire rejected block.
- A very small positive angular increment remains positive rather than being
  rounded to zero by cycle-boundary canonicalization.

## Review

- Self-review covered the complete `origin/main...3faf41c` diff, unit
  conversion, half-open boundary ownership, cycle/frame continuity, coincident
  ordering, buffer partition invariance, finite arithmetic, density bounds,
  and browser/audio independence.
- Self-review corrected three issues before the implementation commit: a fixed
  phase epsilon could absorb legitimate low-speed motion; `sampleOffset` was
  block-relative rather than constrained to the required within-sample
  interval; and a failure after earlier samples in a block could leave partial
  phase progress committed. Regression assertions cover each correction.
- A bounded Terra medium `ticket-worker` implemented the initial phase/event
  modules and tests. The orchestrator retained numerical-boundary corrections,
  integration, Git, reporting, and delivery ownership.
- A fresh Terra high `ticket-reviewer` found that near a cycle boundary the
  fixed epsilon could still advance phase before the physical crossing, and
  that the abrupt a-rate partition test lacked an independent analytic event
  time. The correction removes forward boundary snapping, limits post-wrap
  canonicalization to one millionth of a sample's advance, and adds 44.1/48
  kHz regressions for the reported low-speed case and an analytic 43 1/3-frame
  abrupt-change crossing. The reviewer rechecked the correction, confirmed the
  finding resolved without regressing the 6000 rpm event count or half-open
  rule, and reported no remaining actionable finding.
