## Acceptance evidence

- `tests/engine/dynamics.test.ts` checks the centralized reversible rpm/rad/s
  conversion and linear interpolation with endpoint clamping for the configured
  torque curve.
- A full-throttle sequence verifies that effective throttle starts strictly
  between zero and one after the first millisecond, converges smoothly to one,
  and raises speed by more than 500 rpm. Closing the throttle then lowers speed
  and settles within the asserted 900–1600 rpm idle band.

  | Input point | RPM | Effective throttle |
  | --- | ---: | ---: |
  | Initial closed | 1400.00 | 0.000000 |
  | Full open, 1 s | 3271.96 | 0.999996 |
  | Full open, 3 s | 7247.77 | 1.000000 |
  | Closed, 1 s | 5670.48 | 0.000004 |
  | Closed, 8 s | 1348.39 | 0.000000 |
- Equal one-second inputs at 44.1 and 48 kHz produce exactly equal state, both
  as one block and with an uneven `127, 1, 333, 64, 255, 17` frame partition.
  A repeated 48 kHz run produces the same state, covering determinism and
  accumulator cadence independently of sample rate and block division.
- A 120-second sequence alternates abrupt closed/full throttle and 0/15 N m
  load while advancing uneven 44.1 kHz blocks. Every observed RPM, angular
  velocity, and effective-throttle value remains finite, and speed remains
  non-negative.
- Boundary tests reject out-of-range or non-finite throttle/load, invalid frame
  counts and sample rates, conversion/interpolation overflow, zero or
  numerically unsafe inertia, and single-call advances over 10 seconds. The
  model clamps numerical reverse rotation to zero while rejecting non-finite
  intermediate results before committing a state update.

## Review

- Self-review covered the complete `origin/main...fd1b9e4` diff, the equation's
  torque signs and SI units, idle behavior, throttle time constant, fixed-step
  accumulator boundary, non-negative rotation, deterministic tests, and the
  absence of browser, React, Web Audio, phase, limiter, and UI coupling.
- Self-review found that a positive subnormal sample rate could make elapsed
  time infinite and leave the accumulator loop non-terminating. The prepared
  implementation now rejects conversion and elapsed-time overflow, with
  regression tests for both paths.
- A bounded Terra medium `ticket-worker` implemented the model and independent
  numerical tests. The orchestrator retained Git, integration, boundary fixes,
  review, verification, report, and delivery ownership.
- A fresh Terra high `ticket-reviewer` found two medium-severity boundary
  defects: finite extreme inertia/torque values could overflow and silently
  reset RPM to zero, and a huge accepted frame count could monopolize the
  calling audio thread. The correction rejects unsafe inverse inertia and
  every non-finite intermediate before state assignment, validates torque
  interpolation overflow, and caps one real-time `advanceFrames` call at 10
  seconds while preserving long runs through normal repeated blocks. Regression
  tests cover both findings. Reviewer recheck is pending.
