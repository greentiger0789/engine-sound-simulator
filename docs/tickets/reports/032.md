- UI select options include "6th gear" in proper sequence (`1st gear → Neutral → 2nd gear → ... → 6th gear`). Verified in `tests/e2e/worklet.spec.ts`.
- Keyboard shifting via ArrowUp advances through `1 → N → 2 → 3 → 4 → 5 → 6` and clamps at 6th gear; ArrowDown shifts back down. Verified in `tests/e2e/worklet.spec.ts`.
- Drivetrain settings editor displays `Gear 6 ratio` with initial value `2.8` and can be edited/applied. Verified in `tests/e2e/worklet.spec.ts`.
