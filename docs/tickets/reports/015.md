  all six M3 presets at closed, half, and full throttle at 44.1 and 48 kHz. It
  requires finite PCM, absolute peak at or below 1, no fatal processor message,
  and exact restart-equivalent PCM for the same seed and input.
- `tests/audio/exhaust-resonator.test.ts` verifies 44.1/48 kHz finite impulse
  responses, pathological valid inputs, reset determinism, variable realtime
  frame counts, resonance-band movement when pipe length changes, and bounded
  Nyquist-near response.
- `tests/audio/intake-path.test.ts` verifies opening/load gain and bandwidth
  control, additive bounds, same-seed/reset determinism, realtime frame-count
  handling, and safe runtime mapping of a statically valid above-Nyquist
  resonance.
- Product-level changed-config coverage requires modified intake and exhaust
  parameters to change the rendered PCM, preventing unused configuration fields
  from satisfying the module-only tests.
- `tests/audio/ticket15-spectrum.test.ts` deterministically reproduces the
  source values plotted in the [fixed-condition spectrum figure](015-spectrum.svg).
  It uses a 6000 RPM-equivalent
  50 Hz combustion pulse train, opening `0.5`, load `0.5`, volume `1`, seed
  `12345`, 48 kHz sample rate, and the settled second of a two-second render.
  Moving exhaust resonance from 78 Hz to 286 Hz and intake resonance from 190 Hz
  to 1200 Hz moves the corresponding band energy, while the 22 kHz result does
  not show abnormal edge amplification.
